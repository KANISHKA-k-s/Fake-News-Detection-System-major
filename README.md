# Fake News Detection System using Machine Learning & NLP

##  Objective
This project aims to detect whether a news article is **Fake or Real** using Machine Learning and Natural Language Processing (NLP).

##  Problem Statement
Fake news spreads rapidly on social media and manual verification is difficult. This system automates the detection process.

##  Proposed Solution
- Input: News article text
- Output: Fake (0) or Real (1)
- Uses NLP techniques and ML models for classification

##  Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn
- NLTK / SpaCy
- Matplotlib / Seaborn
- Google Colab

##Methodology
1. Data Cleaning (remove stopwords, punctuation)
2. Text Processing (tokenization, stemming)
3. Feature Extraction (TF-IDF)
4. Model Training (Naive Bayes, Logistic Regression, SVM)
5. Prediction

##  Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score

##  Output
- Classifies news as Fake or Real
- Model accuracy comparison graphs
